# apartment-rental-management-system


## Project Overview
The Apartment Rental Management System is a web-based application developed using Python and Django. It simplifies apartment rental operations by connecting customers, apartment owners, and administrators through a centralized platform.

A full-stack Apartment Rental Management System developed using Python and Django. The platform allows customers to search and book apartments, owners to manage properties, tenants, leases and payments, and administrators to monitor the entire system through dashboards, reports and analytics.

## Technologies Used
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite / PostgreSQL
- **Charts:** Chart.js
- **Version Control:** Git and GitHub

## Main Features

### Customer
- Customer registration and login
- Search and filter apartments
- View apartment details and images
- Add apartments to favorites
- Submit booking requests
- View booking status
- View lease details
- Submit and track payments
- View payment receipts

### Apartment Owner
- Owner registration and login
- Manage buildings, towers and floors
- Add, update and delete apartments
- Manage customer booking requests
- Manage tenants and lease agreements
- Create and manage rent payments
- Verify or reject payment submissions
- View apartment and payment reports

### Administrator
- Admin dashboard
- Manage customers and apartment owners
- Monitor apartment listings
- Manage bookings and leases
- Monitor payment records
- View revenue and occupancy reports
- View analytics and charts

## Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:
   ```bash
   cd apartment-rental-management-system
   ```

3. Create a virtual environment:
   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment on Windows:
   ```bash
   venv\Scripts\activate
   ```

5. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

6. Apply database migrations:
   ```bash
   python manage.py migrate
   ```

7. Start the development server:
   ```bash
   python manage.py runserver
   ```

8. Open the application:
   ```text
   http://127.0.0.1:8000/
   ```
